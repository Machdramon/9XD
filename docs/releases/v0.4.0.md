# 9XD 0.4.0

A larger native-format update, faster 3D loading and a customizable workspace, combining the current Codex and Claude work since 0.3.7.

## Native geometry, materials and textures

- New native readers for Wangan Midnight PS3 XMD, PSP GMO, NFS Most Wanted PC solids, Import Tuner Challenge Xbox 360, Initial D Special Stage PAC/SMD/GIM, RenderWare PS2 and Selene MIX resources. Coverage depends on the supported variants and companion files; these are not universal game importers.
- Genki: automatic global/local track texture context discovery, texture-region and wheel corrections, hierarchy and sampling metadata, and additional validated PS2 VIF geometry paths.
- Initial D Special Stage: corrected Akagi topology, texture preview and PS2 texture addressing to recover previously dark or striped surfaces.
- PGR3/4: improved source material/map inspection, texture-library indexing and scene handedness; base-colour previews remain a subset of the original shaders.
- Super Trucks Racing: improved texture bank linkage, primary UV2 decoding and bounded DMA packet traversal. All enumerated geometry chunks in the ten tested primary track scenes decode. All default surfaces in that corpus have base images assigned; this does not establish full scene placement or shader fidelity.
- Blur: first supported native scenery-object/material previews, split texture resources and multi-section geometry. Selected props are validated; complete maps, all object layouts and full material semantics remain incomplete.

## 3D workflow

- Improved batch loading, progress/rate/ETA reporting and cancellation, mesh provenance and source-map inspection.
- Explicit **Render Default Set** and an option to include alternative geometry/texture sets in **Render All**. Alternatives can overlap weather, LOD or other scene variants.
- Live FOV, camera pose and near/far clipping controls; configurable reference-grid spacing, size and labels.
- Compact Transform / Material / Presets card and contextual viewport controls.
- **Display > Settings > Ignore texture alpha (show textures opaque)** for diagnosing textures whose alpha channel hides geometry. This is a reversible viewport override; source textures and exports are unchanged.

## Interface and usability

- Independent interface styles, panel layouts and themes; Classic, Hackerman CRT, Aqua 2003 and Aero Glass styles, plus Inspector Stack, Command Deck and Floating HUD layouts.
- Included Zuz, Nines, Hackerman and C77 themes; theme roundness, neon, glow and background-gradient options.
- Adaptive inspector layouts and refreshed Structure, Find, Magic Bytes, Checksum and Compare panels; compact controls, collapsible sections and quieter tooltips.
- Improved large-folder file picker and document navigation, scan feedback, About animation and a dedicated Windows runtime cat icon. The original project logo is retained.

## Download and run

Extract **9XD-0.4.0-windows-x64.zip** completely and run **9XD.exe**. Keep the bundled folders and DLLs beside it. Windows 10/11 x64; Vulkan 3D requires a compatible graphics driver. The build is unsigned.

Qt, Python standard library, Vulkan loader, Visual C++/FBX runtimes and the replaceable LZX library are bundled with notices. Ollama/models, C++ compilers, FFmpeg and reconstruction dependencies remain optional separate installations. Video reconstruction and spline tools remain foundations; automatic reconstruction/segmentation is not complete.

## Known limits

Texture assignment percentages describe supported base-image bindings on tested fixtures, not complete shader reconstruction or whole-game coverage. Genki aliases, some external banks, layered materials, secondary UV/effect semantics, Selene placement and Blur full-map reconstruction remain under investigation. Optional fixture tests may be skipped when their local data is unavailable. No game binaries, emulator captures or exported game assets are included; the About splash artwork remains untracked.

## Validation

Clean Windows Release build and portable deployment checks passed. Reader suite: 45 passed, 0 failed, no skips. Full window suite: 132 passed, 0 failed, 86 optional fixture cases skipped. ZIP integrity, GUI subsystem, source executable equality, required runtimes and bundled Python/script-runner checks passed. No game/capture assets or standalone splash image are packaged. A separate clean-machine test remains pending.
