# 9XD 0.4.1

This release adds video reconstruction workflows and initial native RayCity map support.

## Changes

- Video Reconstruction: local video or YouTube URL, metadata inspection, download limits, clip selection, asynchronous FFmpeg frame extraction, progress and cancellation.
- COLMAP sparse reconstruction, saved jobs, camera/point import and a CPU coarse surface preview. Optional CUDA dense reconstruction, fusion and Poisson surface import on compatible hardware.
- Clearer diagnostics for stationary/panoramic footage without sufficient parallax, preserved job results/logs and corrected thumbnail restoration.
- RayCity SCRIPTCE v1 map cells: native placed geometry, normals, material slots, named local/shared DDS banks and textured export. Primary texture/UV0 preview, optional CompleteMap fallback and vertical UV correction.
- RayCity v3 vehicle files show an explicit importer-required result instead of an unexplained empty 3D scan. Embedded DDS images remain inspectable in UV/2D.

## Validation and limitations

- RayCity corpus: 35 cells, 448 parts, 279,747 vertices and 158,186 triangles. All 448 primary texture files resolve with the full client directory; copied study files alone provide 423 textured previews. These figures measure lookup/decoding coverage, not original shader fidelity. The latest vertical UV fix needs visual comparison against the game.
- RayCity vehicle geometry/material import is **not implemented**. Some embedded DDS images are shader masks, not diffuse textures. Original map multi-layer shaders, collision and whole-map deduplication remain pending.
- Sparse/dense reconstruction was exercised with synthetic and real footage; results depend on camera motion, scene visibility and hardware. Scale is uncalibrated. Reconstructed meshes currently have no color/texture atlas; coarse surfaces can contain inferred caps or holes.
- FFmpeg, COLMAP and optional yt-dlp/Deno are separate user-installed tools, not included in this ZIP. CUDA dense reconstruction requires a compatible CUDA-enabled COLMAP build and GPU. Preparation helpers are provided in the source repository. YouTube availability/restrictions can change; use content you are authorized to download.
- Image/spline tools remain a reference/curve-editing workflow; calibrated fitting and segmentation are pending.

## Installation

Extract **9XD-0.4.1-windows-x64.zip** completely and run **9XD.exe**. Keep its folders and DLLs together. Windows 10/11 x64; a compatible graphics driver is required for Vulkan 3D. The build is unsigned.

Your existing settings remain local. Re-scan/re-render RayCity meshes to use the new UV orientation. Optional reconstruction tools and game files are not bundled. Private About artwork is not published as a separate asset.
