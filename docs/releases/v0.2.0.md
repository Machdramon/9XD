# Binary Workbench 0.2.0 — Windows Preview

A portable desktop workspace for binary inspection/editing, texture interpretation, 3D assembly and scripting.

## Changes since 0.1.0

- Advanced Find / Coincidences inspector with scope, alignment, overlap, case filters and navigable/copied results; positional Compare Data inspector with progress and cancellation.
- Image recipe files (`.bwir`), console presets, additional UNORM/FLOAT raw and DDS formats, and per-mesh image textures in Vulkan and the UV view.
- Mesh placement from manual XYZ values or a vector read at a binary offset, with component type, spacing, endian and scale. Unsaved document edits are included. Placement remains adjustable per piece and is included in model exports.
- More vertex formats: signed/unsigned 8/16/32-bit, Float16/32, SNorm/UNorm 8/16 and Fixed16.16; XYZ and homogeneous XYZW. Axis permutations/inversions, independent axis scales and Euler rotations preserve normals and correct reflected face winding.
- Collapsible 3D settings with Expand All / Collapse All.
- Scripting Library Manager with Default Modules and My Modules, a single Add Module workflow, documentation/code views, Python modules/packages and C++ header imports, and enable/disable controls.
- Programmer calculator with simultaneous HEX/DEC/OCT/BIN, 8–64-bit words, signed mode, arithmetic/bitwise operations, shifts/rotations, memory, clickable bits and keyboard control. Theme-aware grouped controls and borderless readings.
- Bundled standard panel arrangement for first-time users, personal layout persistence across upgrades, reset command and a dynamic Toolbars menu.

## Download and run

Download **BinaryWorkbench-0.2.0-windows-x64.zip**, extract the entire ZIP and run **binary_workbench.exe**. Keep all DLLs and bundled subfolders beside it. The GitHub source-code archives are not the runnable Windows application.

Windows 10/11 x64. The package includes Qt, Python and its standard library, the Vulkan loader and Visual C++ runtime files. Vulkan 3D requires a compatible graphics driver. No Qt, Python or Vulkan SDK installation is required for the portable build. The executable is unsigned; C++ scripting requires a local compatible compiler.

## Validation

43 reader tests and 38 interface tests pass; one optional native graphics test is skipped by the automated suite. Packaging validates application dependencies/image handlers and bundled Python scripting with development dependency paths removed. Native Vulkan textured rendering was verified separately during development; validation on a separate clean Windows machine remains pending.

## Current limitations

This is a development preview. Console textures cover specific formats and layouts, not all games or container variants. Image textures/materials are not yet exported with meshes. Arbitrary binary transform matrices, skeletal hierarchies and skinning are not implemented. Compare Data is positional and does not realign inserted/deleted regions. Custom theme editing and translation packs remain planned. See the README and user guide for limits.

The ZIP is accompanied by a SHA-256 checksum. Existing per-user layouts and preferences take priority over bundled defaults.
