# Binary Workbench 0.2.1 — Windows Preview

This update adds a unified theme editor while preserving the workspace, geometry, texture and scripting tools introduced in 0.2.0.

## Theme editor

Open **Other Tools > Settings > Appearance > Themes**.

- Color groups: **Backgrounds**, **Text**, **Accent & Highlights**, **Borders & Separators**, and **Tool Colors**.
- Live preview for controls, hex values, 3D/UV geometry, scripting and calculator samples. Edits stay in the preview until **Apply** or **OK**.
- Create, duplicate, rename and delete custom themes. Included Dark, Light and System themes remain read-only.
- Per-element **Use theme default**, group resets, optional input-field backgrounds and control borders.
- Versioned `.bwtheme` JSON import/export with validation. Personal themes persist independently of upgrades.
- Shared colors for the application palette, Hex Viewer bytes/text/offsets/modified bytes, 3D/UV graphics, scripting/console surfaces and text, and calculator function groups.
- Custom themes based on System follow operating-system appearance changes. Explicit byte-formatting rules and local graphics overrides retain priority.
- Cancel preserves the last applied settings. Built-in themes continue to work with existing profiles.

See [Theme editor documentation](../themes.md) for the supported controls and file format. Syntax-color categories, image checkerboard colors and result/status-specific color groups remain future additions.

## Download and run

Download **BinaryWorkbench-0.2.1-windows-x64.zip**, extract the **entire ZIP** and run **binary_workbench.exe**. Keep all DLLs and bundled subfolders beside it. GitHub's automatically generated source archives are not the runnable Windows application.

Windows 10/11 x64. The portable package includes Qt, Python and its standard library, the Vulkan loader and Visual C++ runtime files. Vulkan 3D needs a compatible graphics driver. The build is unsigned. C++ scripting requires a local compatible compiler.

## Validation

43 reader tests and 39 interface tests pass; one optional native graphics test is skipped by the automated suite. Theme lifecycle, inheritance, import/export, preview isolation, Apply/Cancel and graphics-only color updates are covered. The editor layout was visually checked with Windows fonts.

Packaging validates image handlers, bundled Python and script execution with development Qt/Python paths removed. Separate clean-machine Windows validation remains pending. Console-format, model-export and other limitations described in the README still apply.

The release includes a SHA-256 checksum. Existing personal panel layouts and preferences are preserved.
