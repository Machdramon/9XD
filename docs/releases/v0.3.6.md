# 9XD 0.3.6

9XD 0.3.6 refreshes the Windows interface with a module sidebar, searchable commands and a more compact 3D workspace.

## Highlights

- Refreshed dark/light theme, consistent icons and a configurable primary-action accent.
- Vertical module sidebar with the app logo, Search and Settings shortcuts; drag module tabs to detach them into separate windows.
- **Ctrl+K** command palette for finding modules, menu commands and panel actions.
- Redesigned 3D toolbar with compact view/shading menus and Scan access; larger transform controls, coloured axes and clearer grouped settings.
- Empty-state guidance across mesh, image, analysis and scripting panels.
- Safer detached-module close callback lifetime.

This Windows release carries the visual changes from the macOS branch. macOS build presets, sysroot configuration and MoltenVK changes are not part of this Windows package. Existing native racing-format support from 0.3.5 remains available; recent PCSX2 research does not yet add new material/texture readers.

## Install

Download **9XD-0.3.6-windows-x64.zip**, extract the entire folder and run **9XD.exe**. Keep the DLLs, plugins and Python folder beside it. GitHub source archives are not the runnable application.

Windows 10/11 x64; Vulkan 3D needs a compatible graphics driver. Qt, Python, Vulkan loader, Visual C++ and FBX runtimes and the replaceable LZX library are bundled with notices. Ollama/models and compilers are separate optional installations. The build is unsigned.

Game-specific shaders, all material variants, LOD/instance selection and every console texture format are not fully reproduced. Companion files are required for the decoders that use them. A separate clean-machine check remains pending. See the native format documentation for per-variant scope.

Game binaries, emulator dumps, exported game assets, SDK headers and local build presets are not included in the public release. Standalone About splash artwork remains private; only the public app logo is uploaded as a separate branding asset. A SHA-256 checksum accompanies the ZIP.
