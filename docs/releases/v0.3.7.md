# 9XD 0.3.7

This release adds verified Genki texture/material fixes and the first video and spline modeling tools, with refined inspectors.

## Highlights

- TXRD2 March: primary textures on 19 of 54 decoded parts, correct 4/8-byte UV strides, preserved texture-slot names and clamp sampling in rendering and GLB/FBX export. Other parts can be untextured or use unresolved shader/resource stages.
- TIM2: correct 24-bit image/palette reads and additional strictly validated indexed transfer layouts with 16-bit palettes. All 42 images in the TXR Zero AE86 reference bank decode; this is not a claim of complete scene/material reconstruction.
- **3D → Video Reconstruction**: optional FFmpeg frame extraction runs asynchronously with sampling limits, progress, metadata, thumbnails, cancellation and isolated saved jobs.
- **3D → Image / Spline Modeling**: image reference canvas, grouped curve points, click/drag editing, zoom/pan, reordering and project save/load with validation and unsaved-change protection.
- Themed inspector cards, clearer states, collapsible tools/logs and explicit unavailable pipeline stages.

## Install

Download **9XD-0.3.7-windows-x64.zip**, extract the entire folder and run **9XD.exe**. Keep DLLs, plugins and Python beside it. Windows 10/11 x64; Vulkan 3D requires a compatible graphics driver. The application is unsigned. Source archives are not the runnable application.

Qt, Python standard library, Vulkan loader, Visual C++ and FBX runtimes and the replaceable LZX library are bundled with notices. Ollama/models, C++ compilers and reconstruction tools are optional separate installations. Select an FFmpeg executable in the Video Reconstruction inspector; place ffprobe beside it for video metadata. FFmpeg/COLMAP/Open3D/ONNX Runtime and model weights are not bundled in this ZIP.

## Scope and limits

Frame extraction and image/spline editing are usable foundations. COLMAP sparse reconstruction, camera/point import, calibrated fitting/lofting, segmentation and automatic surface generation are not implemented yet; unavailable pipeline stages stay disabled. The dependency preparation helper is a developer tool using Windows x64 Python 3.12, not an automatic app installer.

Genki external aliases, secondary shaders, LOD selection, some companion-file bindings and game-specific rendering remain incomplete. Native format coverage is documented separately. No game binaries, emulator captures or exported game assets are included. Standalone About splash art stays private; the public logo is supplied separately.
