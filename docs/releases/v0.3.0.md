# 9XD 0.3.0 — Windows Preview

9XD brings the binary, texture, geometry and scripting workspace together with local AI-assisted analysis and native asset scanning. Formerly Binary Workbench; existing personal layouts, settings and recipe formats remain compatible.

## Highlights

- New 9XD identity with a transparent project/application logo.
- Dedicated file, 3D and texture/image scanners. Preview supported discoveries directly and mark recognized structures without changing source bytes.
- Native Genki PS2 0IVX/XMDL and ARCP DMA/VIF reconstruction for validated packet profiles. Recovered triangle strips feed Mesh Collection and normal model export tools; no invented raw index offsets.
- TIM2 discovery walks declared pictures instead of sampling only four, with a bounded 128-image candidate limit.
- Local Ollama assistant with compact replies, document snapshots, controlled binary reads, formatting annotations and real decoder completion receipts. It uses the same native evidence as manual scanning. Install Ollama and a local model separately; neither is bundled.
- FBX export through Autodesk FBX SDK, plus GLB/OBJ/STL; materials and assigned textures are supported on the applicable export paths.
- Expanded 3D editing/viewing: move/rotate/scale gizmos, split and detached views, front/back/top/bottom/left/right orthographic views, grids, frame commands, selection colors, visibility/isolation and XYZ bounds.
- Realistic, cel, simple and wireframe rendering; original vertex normals or face normals, normal/geometry labels and gradient backgrounds.
- Improved mesh recipes, binary-sourced placement and coordinate transforms, file dialog location persistence, color controls and scripting module management.

## Download

Download **9XD-0.3.0-windows-x64.zip**, extract the entire folder and open **9XD.exe**. Keep the bundled DLLs, plugins and Python folders beside it. The source-code archives are not the runnable Windows application.

Windows 10/11 x64. Qt, Python and its standard library, the Vulkan loader, Visual C++ runtime and required FBX runtime are packaged. A compatible graphics driver is required for Vulkan 3D. C++ scripting requires a local compiler. This preview is unsigned.

## Scope and validation

- 45 reader and 59 interface checks pass; optional sample/model/GPU checks run separately.
- Original Genki sample: 867 validated packets, 26,532 vertex records, 21,942 nondegenerate faces; FBX/GLB export and 40 TIM2 surfaces verified, original-file hash unchanged.
- Original ARCP sample: 3,256 vertices and 2,222 faces across 517 independent strips; native GPU rendering and local-AI rendering verified.
- Native GPU checks completed without Vulkan validation errors. Packaging checks image plugins, relocated Python and script execution with development paths removed.
- Profile-specific geometry recovery retains local parts and overlapping variants. Game hierarchy, visibility/LOD selection, material and texture binding remain unresolved. Raw/console layouts outside supported profiles still require explicit recipes.
- Scanning inspects at most 32 MiB; empty results do not prove absence of assets. A clean-machine Windows check remains pending.

See the README, user guide and third-party notices for additional limits. A SHA-256 checksum accompanies the portable ZIP.
