# 9XD 0.3.5

9XD 0.3.5 expands native racing-game asset discovery, linked materials and textures, and large-scene workflows. Supported results load directly from **Scan for 3D Data** into the viewport and export through the normal model tools.

## Highlights

- Native adapters for supported FM1, MSR alpha/retail track, PGR1/2/3/4, NFS Underground 2, R-Tuned and Fast & Furious Xbox study formats. Support is specific to validated structures, not every file from each game.
- PGR3/4 static track discovery with companion STREAM2 resources, native bounded decompression, streamed texture fixes, readable resource hints and one-click Render All.
- NFSU2 geometry/material linkage, shared car texture banks and a native bounded EA HUFF decoder. R-Tuned visual course/car geometry now links supported base images and material groups.
- Separate Genki C1, explicit GIF-strip and TXRD2 v1 topology profiles. TXRD2 selects per-record face suppression from Y or color/alpha according to its validated mesh mode; no universal C1 face rule is applied.
- TXR Zero transfer-form TIM2 decoding: 43 pictures decoded in the reference sample, with 14 supported material bindings. Additional TXR3/TXRD1 multi-model files load and export.
- Hardware-aware performance settings, configurable memory budgets, shared geometry/texture caches and scalable texture uploads for large scenes.
- Faster scan/mesh lists with search, sorting and column controls; multi-selection and batch rendering, clearer cancellation/failure reporting and duplicate prevention.
- Configurable viewport navigation, corrected measurement grid, multi-file open and improved recent-folder/search workflows.
- Expanded native profile documentation and FBX/GLB material/texture export paths.

## Install

Download **9XD-0.3.5-windows-x64.zip**, extract the entire folder and run **9XD.exe**. Keep all DLLs, plugins and the Python folder beside it. GitHub's source archives are not the runnable Windows application.

Windows 10/11 x64. The portable package includes Qt, Python and its standard library, the Vulkan loader, Visual C++ runtime, FBX runtime, and the replaceable native LZX library with source/license notices. Vulkan 3D requires a compatible graphics driver. Ollama/models and C++ compilers are separate optional installations. This build is unsigned.

## Validation

- TXR/Genki/TXRD2: 12 checks passed, including scanner Render All, topology isolation over 23 local files, exact draw-bit mutations and GLB/FBX exports.
- TXRD2 reference cases: 19 groups / 1,692 triangles; 54 groups / 8,328 triangles; 22 embedded groups / 352 triangles.
- NFSU2 HUFF reference corpus: 636 blocks across 32 car archives decoded. Separate native Vulkan validation loaded a 3,104,048-triangle scene with 1,561 groups.
- Release packaging verifies startup/image handlers and relocated bundled Python/script execution without development Qt/Python paths. A separate clean-machine test remains pending.

## Known limits

Companion files must remain available where a decoder requires them. Complete game shaders, dynamic material replacement, all LOD/instance/hierarchy variants and every console texture format are not reproduced. TXRD2 material/texture association and some UV encodings remain pending; the embedded-resource test is not a reconstructed complete track scene. Kaido's distinct face layout, Dreamcast TXR2 and some raw concatenated Genki sections still need investigation. Unsupported structures are reported rather than guessed.

Game binaries, exported game models/textures, SDK headers, local presets and standalone splash artwork are not included in the source repository. See the README and format documentation for the current scope. A SHA-256 checksum accompanies the ZIP.
