# Zero vehicle identification research

Full extracted Zero directory surveyed using GenkiTopology native packet validation. First 160 DAT files inspected, 149 admitted by current topology rules. Raw survey preserved in zero-survey.json with native faces/positions and source paths.

0x00000014.dat selected for vehicle identification. render_zero_14.py reverses Y for presentation, excludes remote auxiliary geometry using robust bounds and omits triangles whose doubled native area is >=0.3, to reveal detailed body hidden by coarse surfaces. Filtering is only for this diagnostic image and must not be used as an extraction repair or exported final mesh. Parts/variants remain superimposed. Exact car identity is pending user confirmation. No application decoder changed.

Earlier 0x000000ba.dat must not be labeled a known car; its identity remains unknown.
