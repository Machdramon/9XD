# 9XD project instructions

## Mandatory coordination and documentation rule

Read `docs/COORDINATION-PLAN.md` before starting project work. It is the shared source of project status and hand-offs for the user, ChatGPT/Codex and Claude.

For every project change, update `docs/COORDINATION-PLAN.md` in the same work session and before reporting completion or handing off. This applies to code, UI, research findings, tests, configuration, documentation and changes to scope or ownership.

Each update must:
- Refresh the `Updated:` date at the top.
- Add or revise the affected task; mark it complete only when its stated outcome is achieved.
- Record what changed, affected files or evidence, validation actually performed, limitations/blockers and the next action/owner.
- Add newly discovered work to the list; keep partial or unverified work visibly pending.
- Update any linked specialist checklist affected by the change, including `docs/research/genki/GENKI-CROSS-ANALYSIS-TODO.md` for Genki research, so it agrees with the shared plan.

A change is not complete until its documentation is synchronized. Do not rely on chat messages as the sole hand-off. Preserve other contributors' uncommitted changes. This rule does not itself authorize commits, pushes, merges, releases or messaging another agent.

Established by the project owner on 2026-10-25; applies to all future project work.
